# Referencias visuales

Este directorio reúne material para consultar al mejorar la estética de la
web. No se carga desde la aplicación pública ni se debe usar una imagen de
mockup como fotografía real de un bowl.

| Carpeta | Uso de referencia |
| --- | --- |
| `brand-identity/` | Logotipo, lenguaje gráfico y paleta. |
| `product-and-packaging/` | Presentación de bowls, tapas, empaques y composición de producto. |
| `merchandising/` | Aplicaciones de la marca en indumentaria. |
| `campaigns/` | Piezas promocionales y tono de comunicación. |
| `web-inspiration/` | Agregar aquí futuras capturas, links exportados o imágenes de referencia para la página pública. |

- `product-and-packaging/bowl-compositions.jpg`: composiciones de bowls y packaging.
- `product-and-packaging/carry-bag.jpg`: bolsa de entrega de Revuelto.
- `merchandising/t-shirt-outdoor.jpg` y `merchandising/t-shirt-collection.jpg`: aplicaciones en remeras.
- `campaigns/loyalty-card.jpg`: tarjeta de fidelización y pieza promocional.

Al sumar una referencia, usar un nombre descriptivo en minúsculas con guiones y
agregar una línea a este índice explicando qué aspecto visual conviene revisar.
